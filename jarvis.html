J.A.R.V.I.S.

A voice-activated AI assistant that listens, thinks, and talks back.

  • Python
  • WebSockets
  • Whisper
  • ElevenLabs
  • asyncio
Still being built. There's no public demo yet. This doc covers the design and progress.

The idea

Typing to an assistant breaks your flow. J.A.R.V.I.S. is meant to feel like talking to someone in the room: you speak, it answers out loud, and it can go do things for you while you keep working.

How it's designed

  1. Listen. Speech is transcribed with Whisper.
  2. Think. An LLM decides what to say and which tools to call.
  3. Act. Function calling for web search, local automation, and system checks.
  4. Speak. Responses are voiced with ElevenLabs, streamed over WebSockets to keep it fast.

Python's asyncio lets it keep listening while background tasks run, and a vector database gives it memory across sessions.
